# Buyer Persona & Intent Engine
## AI Search Strategy & Intent Planning (Production Architecture v1)

Author: WildAutomations.io
Purpose:
This module becomes the intelligence layer before any scraper runs.

The current system flow is:

Keyword
    ↓
Google Search / Google Maps
    ↓
Scraper
    ↓
GROQ
    ↓
Lead Score

This is incorrect because the system searches first and thinks later.

The new architecture must think first and search second.

# DESIGN PRINCIPLES

1. Think before searching.

2. Search buyers, not sellers.

3. Search pain, not businesses.

4. Generate platform-specific queries.

5. Use AI only for planning.

6. Keep scrapers dumb.

7. Keep planner smart.

8. Every search must have a business objective.

9. Every result must contain evidence explaining why it is a good lead.

10. Query quality determines lead quality.
